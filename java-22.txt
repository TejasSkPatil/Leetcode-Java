1️⃣ Assign Cookies

LeetCode #455

Goal: Assign cookies to children so maximum children are satisfied.

Strategy:

Sort children greed values

Sort cookie sizes

Give smallest possible cookie that satisfies the child

Java Code
import java.util.*;

class Solution {
    public int findContentChildren(int[] g, int[] s) {
        Arrays.sort(g);
        Arrays.sort(s);

        int i = 0, j = 0;

        while(i < g.length && j < s.length){
            if(s[j] >= g[i]){
                i++;
            }
            j++;
        }
        return i;
    }
}
