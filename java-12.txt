Longest Increasing Subsequence (LeetCode 300):
 Concept:

For each element:
Check all previous smaller elements.

Java Code:
import java.util.Arrays;

class Solution {
    public int lengthOfLIS(int[] nums) {

        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);

        int max = 1;

        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] > nums[j]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            max = Math.max(max, dp[i]);
        }

        return max;
    }
}

⏱ Time: O(n²)
💾 Space: O(n)
